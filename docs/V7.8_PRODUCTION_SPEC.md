# V7.8 Production Spec

Status: production-assumption note for the current `mnt_bot V 7.8 plus.py` path. This file records execution and data assumptions that must not be inferred from the older candidate spec alone.

## Manual Execution Policy

V7.8 is a signal and manual-execution workflow. It does not submit broker orders.

The operator reviews the generated signal, live signal, and adjustment tables, then places orders manually. Because of that, broker-order idempotency, paper/live mode separation, and automated kill-switch logic are outside the current production scope.

## Sub-A And ADK Execution Policy

Sub-A and Sub-A-DK / ADK intentionally use the following production assumption:

- intraday or near-close live signal is checked before market close;
- the same trading day's signal is used for the manual execution decision;
- execution is intended at that trading day's close price.

This is a deliberate design choice, not a bug. Formal reports and reviews should describe this as "T close live signal -> T close manual execution" for these A-share sleeves.

Any change to this assumption would be a strategy-design change, not a bug fix. Tests and displays should keep `signal`, `live signal`, `params`, and `live params` aligned with this policy.

ADK 的 Top-3 表只表示两条子策略各自的基础排名，不是最终执行清单。Top-1 仍需经过同向过热、score-hot、VolScale 等覆盖层；查询页必须在 Top-1 同一行标明覆盖层后的最终持仓或“过滤后为空仓、不执行”，实盘以最终执行仓位和账户级净敞口为准。

## Sub-B Execution Policy

Sub-B remains on the US execution rule:

- T close signal;
- T+1 adjusted open execution;
- T+1 close return.

VolReg follows the same rule. On a VolReg cash-entry day, the backtest keeps the previous effective holding's overnight return from prior close to current open, then moves to cash for the intraday segment. On a VolReg cash-exit day, it stays cash overnight and applies the restored model holding from current open to current close.

Formal Sub-B runs must not silently replace a missing adjusted open price with the same day's close. The official strategy path runs Sub-B legs and Sub-B overlays in strict open-execution mode: if a required T+1 adjusted open is missing for an active holding or target holding, the run fails and the missing date/asset must be fixed before the result is used. Lenient close fallback is retained only for lower-level research helpers when they are called without strict mode.

## External Gate Freshness Policy

External Poe gates and ADK allowed tables must cover the full target price index before they are forward-filled.

If a gate source ends before the target price index ends, the overlay run must fail instead of extending the last gate state. This applies at least to:

- Sub-B US long active-by-sleeve table;
- ADK allowed daily tables.

Forward-fill is allowed only inside the covered source window, not beyond the source's final date.

## Manual Run Checklist

Before using a V7.8 signal, live signal, params, live params, or performance output for a manual execution decision, record these checks:

- CN close latest date: confirm the A-share close frame reaches the intended decision date for Sub-A and ADK.
- US close latest date: confirm the Sub-B close frame reaches the intended US signal date, without compressing the US/crypto calendar to A-share sessions.
- US adjusted open coverage: confirm every active or target Sub-B asset has the required T+1 adjusted open; formal runs must fail rather than use close fallback.
- Sub-A volume overlay: confirm whether the hard Sub-A amount/volume overlay is fresh, unavailable, or unresolved; unresolved signal-query displays must not be treated as normal executable sizing.
- External gates: confirm Sub-B active gates and ADK allowed tables cover the full target index before forward-fill.
- Microcap/Sub-D: refresh and review their independent official outputs before using them in four-sleeve or five-sleeve portfolio decisions.
