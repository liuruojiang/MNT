- 权重显示顺序：`Sub-A / ADK / Microcap / Sub-B`
- 近期加权窗口：1Y 15%，3Y 35%，5Y 35%，10Y 15%

## 全样本结论

完全无约束时，最高年化会退化成 100% Microcap，年化 37.69%，MaxDD -11.29%。这不是一个合理的四策略组合答案。

在实用约束下，当前 V7.2 的 `10/15/15/60` 偏保守且偏向 Sub-B。若目标是同时提升年化并不恶化最大回撤，最优区域明显应该提高 Microcap 和 ADK，降低 Sub-B。

推荐第一候选：

```text
Sub-A 12.5% / ADK 20.0% / Microcap 32.5% / Sub-B 35.0%
```

理由：

- 全样本年化从 28.59% 提高到 31.48%。
- 全样本 MaxDD 从 -7.20% 改善到 -6.76%。
- Sharpe 从 2.31 提高到 2.70，是扫描中的实用约束 Sharpe 最优。
- 不是极端押注单腿，四个子策略都保留了有意义权重。

如果更偏收益：

```text
Sub-A 5.0% / ADK 22.5% / Microcap 42.5% / Sub-B 30.0%
```

这组在不劣于当前 MaxDD 的条件下年化最高，年化 32.95%，MaxDD -7.17%。缺点是 Sub-A 降到 5%，Microcap 提到 42.5%，更偏进攻。

如果更偏回撤：

```text
Sub-A 22.5% / ADK 10.0% / Microcap 25.0% / Sub-B 42.5%
```

这组把 MaxDD 控制到 -5.99%，年化仍有 29.66%，但收益改善有限。

## 近期加权结论

如果按用户指定方向，更重视最近 `1Y / 3Y / 5Y / 10Y`，并让 `3Y / 5Y` 权重更大，结论会变化：

- 近期加权权重：1Y 15%，3Y 35%，5Y 35%，10Y 15%。
- 当前 V7.2 的近期加权指标：年化 32.80%，Sharpe 2.53，加权 MaxDD -5.94%，Calmar 5.60。
- 近期窗口里 Sub-A 表现明显强，因此近期加权最优会把 Sub-A 提高到 40%~55%，而不是继续大幅加微盘。

近期加权核心候选：

| 定位 | 权重 A/ADK/微盘/B | 加权年化 | 加权 Sharpe | 加权 MaxDD | 加权 Calmar |
|---|---|---:|---:|---:|---:|
| 当前 V7.2 | 10.0 / 15.0 / 15.0 / 60.0 | 32.80% | 2.53 | -5.94% | 5.60 |
| 近期加权收益最高 | 60.0 / 5.0 / 5.0 / 30.0 | 34.92% | 2.17 | -7.58% | 4.70 |
| 近期加权收益且不劣于当前加权 MaxDD | 55.0 / 5.0 / 10.0 / 30.0 | 34.43% | 2.42 | -5.85% | 5.97 |
| 近期加权 Sharpe 最优 | 27.5 / 12.5 / 20.0 / 40.0 | 33.30% | 2.70 | -5.66% | 6.01 |
| 近期加权 Calmar 最优 | 50.0 / 5.0 / 15.0 / 30.0 | 34.05% | 2.57 | -5.22% | 6.60 |

近期窗口下，我不建议采用 `60 / 5 / 5 / 30`，虽然加权年化最高，但 Sharpe 降到 2.17，且加权回撤变深到 -7.58%，本质上是在押最近 Sub-A 强势延续。

更合理的近期加权候选有两个：

1. 收益/风险均衡：`27.5 / 12.5 / 20.0 / 40.0`
   - 加权年化 33.30%，高于当前 32.80%。
   - 加权 MaxDD -5.66%，好于当前 -5.94%。
   - 加权 Sharpe 2.70，是近期加权 Sharpe 最优。
2. 更进攻但仍控制回撤：`50.0 / 5.0 / 15.0 / 30.0`
   - 加权年化 34.05%。
   - 加权 MaxDD -5.22%，明显好于当前。
   - 缺点是 A 权重 50%、ADK 5%，对最近 A 强势依赖更高。

综合近期权重后，我更偏向把 V7.2 默认候选从上一版 `12.5 / 20 / 32.5 / 35` 调整为：

```text
Sub-A 27.5% / ADK 12.5% / Microcap 20.0% / Sub-B 40.0%
```

这组没有过度押单腿，近期加权 Sharpe 最高，同时加权回撤也优于当前 V7.2。
