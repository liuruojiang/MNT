## 固定存放与运行

代码入口：`tools/run_data_source_service.py`；本机存储：`D:\动量策略\_data_source_service`。

```powershell
$env:PYTHONUTF8='1'
$env:PYTHONDONTWRITEBYTECODE='1'
python -B tools/run_data_source_service.py --config D:\动量策略\_data_source_service\config.json --mode incremental --cn-mode tail
```

`latest.json` 指向本次评估，报告内 `REVIEW_REQUIRED` 表示仍有未验收字段，进程返回 0 仅表示评估执行完成。失败会写 `FAILED`，不得打开旧正常报告冒充本次成功。`--mode reuse --cn-mode archive` 仅复核存档，不联网；已过截止日的归档会失去资格。

本地 SQLite 保存请求额度、问题状态、源头索引与研究资格；原始响应按 SHA256 不可覆盖存放。密钥仅为原 Windows 用户加密的 DPAPI 文件副本，位于 `secrets`，原件保留；Git、报告、日志、打包均不包含密钥。跨用户或跨机必须重新安全配置，复制密文不等于目标机可用。

初始化入口 `tools/init_data_source_service.py` 只接受明确的旧加密凭证目录、原美股成功归档和原万得归档路径，不覆盖不同的现有密文。当前机器已完成初始化，不需要重复迁移。

## 更新与质量控制

- Tiingo：有新截止日时读取 10 天重叠增量；新公司行动、重叠复权改变或满 7 天历史复查时，要求完整历史更新，禁止拼接不一致复权前缀。Yahoo 每次到期读取该品种完整原生历史，检测历史回改；同截止日 24 小时内复用。
- 本地每源每小时上限 30 次请求，跨进程重启保存；额度不是供应商授权额度保证。认证、网络或额度失败隔离对应源，停止继续请求，不回退旧正常快照。手动与每日任务使用同一运行锁。
- 独立 XNYS 日历复用正式 V8 已审纯日历函数，验证入口哈希，不导入或执行 bot。规则范围 2003–2027，历史 PIT 资格单列；中国独立交易所日历目前仅覆盖 2026。美国保守地在纽约 21:00 后、中国在上海 16:00 后确认当日收盘。超出日历范围直接拒绝，需要先维护日历。
- 已确认现金参考同时校验事件及复权因子，避免两家共同漏配却互相“验证通过”。提供商的原始字段和复权习惯保留，拆股基准换算仅用于比较副本。服务不自动修复价格。
- `source_audit.adapters.read_asset` 仅允许 `research_only`、已登记项目/品种、准确截止日和已合格字段；成交量未通过不能随价格获取。开始新评估先撤销旧资格；失败、过期或未知字段均拒绝。当前只有部分美股价格形成研究快照，不能视为全项目或生产验收。
- 问题按证据指纹去重；已完成事件不重新成为任务。新增冲突、质量门状态改变（包括上游修正）才通知，自动化不运行策略回测。
