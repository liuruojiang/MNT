# V7.7 Sub-C IEI 趋势过滤研究与清理同步记录 2026-06-01

## 目的

研究 C 策略中 `VGIT` 历史代理替换为 `IEI` 后，是否可以用周线 MA 或周线绝对动量的各资产级过滤规则，在保留年化收益较多的情况下压低最大回撤。

本次只做研究记录和测试文件清理，未修改 `mnt_bot V 7.7 plus.py` 生产逻辑。

## 统一口径

- 入口脚本：`mnt_bot V 7.7 plus.py`
- 研究代理：组合持仓名仍为 `VGIT`，但历史价格代理改为 `IEI`
- 数据窗口：`2007-07-27` 到 `2026-05-29`
- C 策略基准：`PROD_USE_TIMING=False`，现有 Sub-C 目标波动率缩放开启
- 执行假设：周线信号在周收盘确认，下一日开始生效
- 过滤方式：各资产独立触发；谁触发，谁降仓或清仓，其他资产不受影响
- 防守资产：触发后减出的仓位转入 `BIL`
- 组合测试：两条原始收益流先 `50/50` 混合，再统一套一层当前 Sub-C 目标波动率缩放

## 关键结果

### 清仓版 50/50 组合

`周MA26清仓` 和 `周绝对动量20清仓` 各占 50%。

| 方案 | 全样本 年化 / 回撤 | 15Y 年化 / 回撤 | 10Y 年化 / 回撤 | 5Y 年化 / 回撤 |
|---|---:|---:|---:|---:|
| 当前基准 C + 目标波动率 | 10.56% / -33.96% | 11.24% / -23.34% | 14.26% / -23.34% | 13.14% / -23.34% |
| 周MA26清仓 | 8.95% / -15.99% | 8.37% / -14.68% | 11.81% / -12.90% | 12.40% / -12.90% |
| 周绝对动量20清仓 | 8.61% / -15.82% | 8.63% / -14.57% | 12.40% / -11.56% | 13.33% / -11.31% |
| 两者 50/50 组合 | 8.94% / -15.07% | 8.67% / -13.75% | 12.33% / -11.92% | 12.90% / -11.92% |

### 保留 25% 版 50/50 组合

`周MA26触发后保留25%` 和 `周绝对动量20触发后保留25%` 各占 50%。

| 方案 | 全样本 年化 / 回撤 | 15Y 年化 / 回撤 | 10Y 年化 / 回撤 | 5Y 年化 / 回撤 |
|---|---:|---:|---:|---:|
| 当前基准 C + 目标波动率 | 10.56% / -33.96% | 11.24% / -23.34% | 14.26% / -23.34% | 13.14% / -23.34% |
| 周MA26 保留25% | 9.61% / -17.83% | 9.55% / -15.96% | 12.79% / -15.96% | 12.77% / -15.96% |
| 周绝对动量20 保留25% | 9.46% / -20.35% | 9.72% / -15.23% | 13.29% / -15.23% | 13.24% / -15.23% |
| 两者 50/50 组合 | 9.66% / -18.50% | 9.71% / -15.04% | 13.10% / -15.04% | 12.94% / -15.04% |

## 结论

- 如果优先压回撤：清仓版 50/50 更强，全样本最大回撤约 `-15.07%`，但全样本年化降到约 `8.94%`。
- 如果希望收益少牺牲一些：保留 25% 版 50/50 更均衡，全样本年化约 `9.66%`，最大回撤约 `-18.50%`。
- 两个版本都明显改善当前 C 策略目标波动率基准的最大回撤，但都存在年化收益折损。
- 当前记录为研究候选，不代表已经同步到生产信号、实盘查询、参数展示或 live 参数页面。
