## 修复内容


| 问题 | 修复后的行为 |
|---|---|
| B 每日 VolReg 被周度信号日拦截 | 模型周度事件和每日风控分别判定；确认的风控在下一美股开盘执行；四查询与 Excel 共用状态 |
| ADK 缺价被补值掩盖 | 合并前验证原始观测，上市后内部及末尾缺日拒绝，不再无限补值 |
| A 股非法价格与新鲜度遗漏 | 零、负数、无穷、上市后 NaN 拒绝；盘前/周末同样检查最近应有收盘；今日快照不能掩盖缺失前收 |
| C 年度交易没有记录/提示 | 独立年度 MOC 目标和带实际执行时刻记录；收盘前不冒充已执行，完成后不重复提示 |
| C 缩放日收益计算失真 | 旧持仓承担隔夜，开盘净值支付费用并调整，然后计算新持仓日内收益和融资 |
| B7.8/B7.9 名称绕过执行过滤 | 按策略族及事件类型确定实际执行日；C 按明确执行时间过滤 |
| 完整单日被误解为月份范围 | 完整日期优先解析，非法日期和逆序范围明确报错 |
| B 固定权重与无交易持仓不一致 | 真实证券份额及债务逐日计账，无事件自然漂移；仅确认事件开盘交易并支付实际费用 |
| 周六元旦错误提前休市 | 修正 NYSE 元旦规则，2021 年末 MOC 恢复为 12 月 31 日 |
| B7.8 VEA/EFA 开盘与收盘尺度不一致 | 开盘与收盘使用相同 B7.8/B7.9 资产映射；上市后 EFA 代理开盘使用同源 VEA 及相同衔接系数 |
