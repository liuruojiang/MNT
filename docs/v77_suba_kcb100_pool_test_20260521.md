## 结论

科创100比科创50更值得继续研究纳入 A 池。它在基日回填、正式发布后、近5年、近3年、近1年窗口都提高了年化收益；主要代价是波动率上升，且 5年与3年最大回撤变深。正式纳入前的关键问题是指数口径：当前测试使用价格指数代理，而现有 Sub-A 主池以全收益指数为主。
