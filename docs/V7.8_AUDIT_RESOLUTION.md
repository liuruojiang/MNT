# V7.8 Audit Resolution

Date: 2026-06-28

This note freezes the P0/P1/P2 audit remediation stage for `mnt_bot V 7.8 plus.py`.

## Scope

Included files:

- `mnt_bot V 7.8 plus.py`
- `run_v78_substrategy_poe_overlay_test.py`

- `docs/V7.8_PRODUCTION_SPEC.md`
- `docs/V7.8_AUDIT_RESOLUTION.md`

## Resolved P0

1. Sub-B VolReg execution timing was aligned to the formal Sub-B rule:
   `T close signal -> T+1 adjusted open execution -> T+1 close return`.
   VolReg cash-entry days keep the old holding's overnight return and then move to cash intraday.
   VolReg cash-exit days stay cash overnight and apply the restored model holding from open to close.

2. External gate stale forward-fill was blocked for formal overlay runs.
   Sub-B active gates and ADK allowed tables must cover the full target index before forward-fill.
   If a source ends before the target price index, the run fails instead of extending stale state.

## Resolved P1

1. Formal Sub-B paths now run in strict open-execution mode.
   Missing required T+1 adjusted open prices for active or target Sub-B assets fail the run instead of silently falling back to same-day close.

2. Strict open execution is passed through the official Sub-B leg, EMA leg, V7.8 bias leg, V7.8 logvol leg, VolReg overlay, and DBC profit guard overlay.

## Resolved P2

1. The Sub-B parameter display no longer describes the backtest as close-to-close plus `shift(1)` approximation.
   It now states the T+1 adjusted-open rule and the fail-fast behavior for missing required opens.

2. `docs/V7.8_PRODUCTION_SPEC.md` now contains a manual run checklist covering CN/US data freshness, US adjusted-open coverage, Sub-A volume overlay status, external gate coverage, and Microcap/Sub-D independent refresh.

3. Regression tests cover the stale-gate checks, VolReg open execution, strict Sub-B open execution, and the display/documentation guardrails.

## Not Adopted

These were removed from the fix list because they are intentional design choices or already covered by existing strategy assumptions:

- Sub-A and ADK same-day near-close live signal used for same-day close manual execution.
- Broker automation, idempotency, paper/live split, and automatic kill-switch work, because V7.8 is a signal and manual-execution workflow.
- Additional transaction-cost splitting, because the current configured costs are treated as the production assumption.
- Extra mixed-parameter scans, because these parameter combinations were already tested before promotion.
- Account-level automatic execution backtest, because manual execution is the production workflow.
