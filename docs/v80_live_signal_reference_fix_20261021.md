- 价格/分腿日期不一致、必要缩放或状态缺失、坏价或可用历史中断时，明确显示参考不可用。

- 信号、实时信号、参数、实时参数共用概览；参考不改账户、执行目标、周度/VolReg 指令或 Excel。
