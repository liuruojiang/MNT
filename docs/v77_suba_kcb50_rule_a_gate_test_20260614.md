# V7.7 Sub-A 叠加 A 股子策略与科创50 Rule A Gate 测试记录

日期: 2026-06-14

## 目的

记录本轮针对 V7.7 Sub-A 的三组研究测试:

- 用已有 A 股单腿子策略 gate 叠加 V7.7 Sub-A，比较规则 A 与规则 B。
- 将科创50价格指数加入 V7.7 Sub-A A 策略池，观察不加子策略 gate 的影响。
- 在加入科创50后，用科创50子策略 `kcb50_long_momentum_v1_2.py` 按规则 A 过滤科创50持仓。

## 规则口径

规则 A: V7.7 Sub-A 先按原规则排名并判断是否允许开仓或持仓；如果选中的标的有对应单腿子策略 gate，则只有该 gate 同时发出持仓信号时才允许持仓，否则转现金。未覆盖的标的，例如中证红利低波100，不受该 gate 限制，继续按 V7.7 原规则执行。

规则 B: V7.7 Sub-A 仍先按原规则产生候选排序，但只在 V7.7 本身允许开仓或持仓的候选内向下寻找第一个通过对应子策略 gate 的标的；未覆盖标的按 V7.7 原规则通过。不做无限向下选择。

科创50 gate: 使用 `D:\动量策略\A 股股指多头策略\kcb50_long_momentum_v1_2.py` 的 `final_weight`。该子策略说明为 T 收盘计算信号、作用到 T+1 close-to-close 收益，因此在 V7.7 收盘决策日使用 `final_weight.shift(-1) > 0` 对齐。

## 代码与数据口径

- V7.7 脚本: `mnt_bot V 7.7 plus.py`
- 科创50子策略脚本: `D:\动量策略\A 股股指多头策略\kcb50_long_momentum_v1_2.py`
- V7.7 Sub-A 路径: `fetch_cn_kline()` -> `_add_cn_bond_column()` -> `run_cn_strategy()` -> MA60 同侧过热 overlay -> Sub-A 成交额 overlay
- 成本和风控: `CN_COMMISSION=0.001`, `CN_TARGET_VOL=0.30`, `CN_MAX_LEV=1.5`; 保留 R2、20日绝对动量、同侧过热、Sub-A 成交额 overlay
- 科创50价格指数: `1.000688`; Sina OHLCV 2020-01-02 至 2026-06-12, 1560 行
- 科创50正式评价起点: 2020-07-23。2020-07-23 前的价格历史只用于指标 warmup，不纳入正式窗口结论。
- 科创50 ETF 首批上市日: 2020-11-16。本轮用价格指数测试，不用 ETF 作为执行价格。
- 稳定性处理: 最终科创50 Rule A runner 将 Sub-A 成交额 overlay 信号只加载一次，并在三组变体中复用，避免外部成交额数据重复抓取导致变体间对照漂移。

## 结果一: 已有 A 股子策略 Gate 叠加 V7.7 Sub-A

窗口: 2015-02-10 至 2026-06-12。该组不涉及科创50；红利低波100因没有对应子策略 gate，按 V7.7 原规则通过。

| 窗口 | 原 V7.7 年化 / 最大回撤 | 规则 A 年化 / 最大回撤 | 规则 B 年化 / 最大回撤 |
|---|---:|---:|---:|
| Full | 33.55% / -24.73% | 32.02% / -23.29% | 28.38% / -30.60% |
| 10Y | 30.90% / -24.73% | 31.06% / -23.29% | 26.42% / -23.46% |
| 5Y | 41.95% / -12.72% | 43.26% / -11.28% | 40.67% / -15.25% |
| 3Y | 62.16% / -11.28% | 63.76% / -11.28% | 59.33% / -15.25% |
| 1Y | 94.83% / -11.28% | 96.95% / -11.28% | 114.56% / -10.64% |

观察: 规则 A 更像风险过滤，长期表现优于规则 B；规则 B 近 1Y 收益更高，但长期回撤和收益质量明显弱。

正式窗口持仓统计:

| 变体 | 科创50持仓天数 | 权益持仓天数 | 国债持仓天数 | 现金天数 |
|---|---:|---:|---:|---:|
| 原 V7.7 | 0 | 927 | 21 | 939 |

科创50 gate 审计:

- 科创50子策略正式窗口 gate 有效天数: 618 / 1427
- V7.7 在正式窗口内原始选中科创50: 253 天
- 其中被科创50子策略 gate 阻断: 41 天
- 通过 gate 的原始选中日: 212 天
- 最终实际科创50持仓: 177 天
- 2026-06-12 子策略 `final_weight_for_current_return_row=0.0`，V7.7 决策日 gate 为 false

观察: 科创50 Rule A gate 显著削弱了“加入科创50”的 Full/5Y 收益增量，但保留了 3Y/1Y 的改善，且 1Y 回撤显著优于不加 gate 版本。Full 窗口最大回撤没有改善，仍为 -18.15%，因此不宜仅凭近端窗口直接推广为生产规则。

## 结论

1. 对已有 A 股单腿子策略，规则 A 明显比规则 B 更适合作为 V7.7 Sub-A 的约束方式；规则 B 的长期收益和回撤更差。
2. 科创50加入 V7.7 Sub-A 池子本身能提升收益，但代价是正式窗口回撤加深。
3. 科创50子策略 Rule A gate 对近端 3Y/1Y 有正贡献，尤其 1Y 改善明显；但 Full/5Y 的收益改善弱于不加 gate，Full 最大回撤仍未修复。
4. 这轮结果应作为研究记录，不直接改生产 `mnt_bot V 7.7 plus.py`。若后续考虑生产化，需要进一步做成交额 overlay 固定源、科创50执行标的口径、全收益/价格指数差异、以及加入全套 A 股子策略 gate 后的共同样本复核。
