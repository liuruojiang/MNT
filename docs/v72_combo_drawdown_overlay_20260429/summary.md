## Overlay 规则

测试的是组合级净值回撤 overlay：

- 用前一日“已应用 overlay 后的组合净值”计算当前回撤。
- 如果回撤达到触发阈值，下一日把整个 V7.2 组合风险敞口降到指定比例。
- 单阈值规则采用滞后退出：触发阈值的一半作为恢复退出阈值。例如 `dd4_scale80` 表示回撤达到 -4% 后降到 80%，回撤修复到 -2% 内再恢复 100%。
- 主口径包含 overlay 额外交易成本：每 100% 仓位变动 10bp。底层策略自身费用沿用原策略路径。

## 最终决策

本轮测试后不把组合级净值回撤 overlay 纳入 V7.2 默认规则。

原因：V7.2 baseline 自身回撤已经较浅，overlay 带来的最大回撤改善不足以覆盖年化收益损失。当前更适合保持 V7.2 的简单组合口径：Sub-A 10% / Sub-A-DK 15% / Microcap 15% / Sub-B 60%。

## 结论

组合级净值回撤 overlay 有一定帮助，但帮助只是“温和控回撤”，不是显著提升收益或 Sharpe。

- V7.2 baseline 本身全样本最大回撤只有 -7.20%，已经比较浅。6% 或 8% 触发通常太晚，对最大回撤几乎没有改善。
- 真正有效的是 4% 触发。`dd4_scale80` 把全样本最大回撤从 -7.20% 降到 -6.62%，年化从 28.59% 降到 27.40%，是比较轻的保险。
- 如果更重视回撤，`dd4_scale60` 把最大回撤降到 -6.24%，但年化降到 26.05%，防守状态约 24.8% 的交易日，收益牺牲更明显。
- `dd4_scale50` 回撤最低，但年化和总收益损失过大，不适合作为默认。
- 阶梯式 `tier_dd4_6_8` 切换次数很多，成本后 Sharpe 和 Calmar 不占优，不如简单单阈值。

建议：本轮不落地默认 overlay。只把 `dd4_scale80` 作为后续风险工具箱候选；如果未来 V7.2 实盘组合回撤显著扩大，再重新评估是否启用。
